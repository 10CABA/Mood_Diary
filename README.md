# Дневник настроения
Клиентское веб-приложение для ежедневной фиксации настроения с аналитикой, редактированием и историей записей.


# Запуск
1. Скачать или клонировать репозиторий
2. Открыть файл 'index.html'


# Функции
* Добавление записи с оценкой настроения от 1 до 5
* Текстовая заметка до 200 символов
* Ограничение: одна запись в день
* Редактирование и удаление сегодняшней записи
* История записей с фильтрацией по датам
* Символьный график динамики за последние 7 дней
* Хранение данных в localStorage

# Структура
├── index.html 
├── style.css
├── script.js
├── imgs
│   └── Dots.png
└── README.md

Каждая запись хранится как объект в масиве 'entries':
{
  "id": "идентификатор",
  "date": "дата",
  "mood": оценка_настроения,
  "note": "текст_заметки"
}
